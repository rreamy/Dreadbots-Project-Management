# Dreadbots Project Management Frontend

This frontend is a lightweight React app for a robotics team project board. It is designed to work with the Spring Boot API in the same repository.

## Setup

1. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```

2. Run the app:
   ```bash
   npm run dev
   ```

3. The app runs on:
   - http://localhost:5173

## Notes
- This app assumes the backend is running on localhost:8080.
- It supports login, story viewing, and story creation.
- It is intentionally simple to stay easy to maintain.
